# Changelog

## 1.1.0 — 2026-09-20

Все 19 Project-страниц ведут от минимального экрана к работающему приложению через 110 последовательных шагов. Перед решением есть самостоятельная попытка; после него — ожидаемый результат, разбор новых понятий и небольшие проверки понимания. Решения показывают изменения с местом вставки, полный набор файлов находится в закрытом Reference в конце.

### Что изменилось относительно 1.0.1

| Проект | Итоговая переработка |
| --- | --- |

### Проверки и оформление

- Новый `scripts/check-project-swift.py` восстанавливает накопленный код непосредственно из напечатанных фрагментов и сравнивает его с Reference. Режим `--typecheck` проверяет каждый шаг через установленный iOS SDK.
- Валидация проверяет порядок «попытка → скрытое решение → результат → объяснение», нумерацию без ограничения количества шагов, непустые решения и итоговые файлы.
- Браузерный тест проверяет раскрытие первого решения и закрытое состояние следующего на всех 19 Project-страницах, а также прежние 50 маршрутов, поиск, прогресс и навигацию.
- Добавлено спокойное оформление блоков решений с видимым keyboard focus; уменьшен заголовок мобильной шапки, чтобы меню помещалось по ширине.

Milestones, маршрут just-in-time, URL страниц и пользовательская база не менялись. Проверка типов Swift не заменяет запуск приложений на физическом устройстве: камера, VoiceOver, биометрия, уведомления и жесты требуют отдельной ручной проверки.

## 1.0.1 — 2026-09-17

Точечная правка внутренней последовательности курса без изменения его архитектуры.

### Beginner-first

- Swift Testing в первой контрольной перенесён из обязательных требований в возврат после Day 17;
- решение конвертера теперь действительно использует `enum` для единиц;
- generic `Card<Content: View>` убран из основного примера Project 3 и отложен до Day 18;
- checkpoint Day 7 переписан без optionals, `guard let` и `reduce`.

### Воспроизводимые проекты

- BetterRest получил учебный CSV, пошаговое создание `.mlmodel` и полный вызов `SleepCalculator` без placeholder;
- Drawing получил полный рабочий `Spirograph` со sliders и анимацией;
- iExpense показывает ошибки persistence вместо молчаливого `try?`;
- Hot Prospects теперь наглядно изменяет общий observable state между вкладками;
- migration старого SwiftData store в Milestone 10–12 стала необязательным advanced-заданием;
- Day 0 теперь описывает маршрут Day 1–15 → проекты → bridge articles just-in-time.

## 1.0.0 — 2026-09-17

Первая отдельная статическая версия курса для GitHub Pages.

### Содержание

- опубликованы 21 статья, 19 SwiftUI-проектов и 5 milestones;
- основной маршрут перестроен по принципу beginner-first и just-in-time;
- добавлена единая version policy;
- проекты начинаются с полного компилируемого vertical slice;
- сложные и узкие темы перенесены в optional-блоки «Глубже».

### GitHub Pages

- добавлена автоматическая сборка и публикация из ветки `main`;
- все внутренние ссылки и favicon адаптированы к подпути `/learn-swift/`;
- сохранены поиск, карта курса, related content, темы оформления и адаптивный интерфейс.

### Отличия от серверной версии

- удалены аккаунты, профиль, Google OAuth и восстановление доступа;
- удалены комментарии и административные действия;
- удалены API, Flask, SQLite, конфигурация VPS и серверные зависимости;
- прогресс хранится только локально в браузере;
- кнопка «Продолжить» открывает первый непройденный шаг по локальным отметкам.
