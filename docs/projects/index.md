# SwiftUI Projects

Проекты идут по нарастающей: первые знакомят с View и state, следующие добавляют data flow, persistence, networking, graphics, accessibility и adaptive layout. Карточка показывает готовность по теории, но ничего не блокирует.

Общие версии и baseline описаны в [version policy](/version-policy). Если проект использует более новый API, статья отмечает это рядом с примером. Каждый Project — сначала небольшой компилируемый vertical slice, затем самостоятельное изменение и только потом необязательное углубление.

::: info Swift остаётся основой
В каждом проекте новые SwiftUI APIs опираются на знакомые Swift-концепции: Arrays, closures, structs, protocols и optionals.
:::
