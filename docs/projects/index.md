# SwiftUI Projects

Проекты идут по нарастающей: первые знакомят с View и state, следующие добавляют data flow, persistence, networking, graphics, accessibility и adaptive layout. Карточка показывает готовность по теории, но ничего не блокирует.

Общие версии и baseline описаны в [version policy](/version-policy). Если проект использует более новый API, статья отмечает это рядом с примером. Каждый Project начинается с минимального компилируемого состояния и ведёт через небольшие шаги: сначала самостоятельная попытка, затем скрытое решение, ожидаемый результат и только новые концепции. Решения содержат изменения с точными местами вставки, а после них разобран смысл новой записи. Полный итоговый код находится в конце статьи в сворачиваемом reference-блоке.

::: info Swift остаётся основой
В каждом проекте новые SwiftUI APIs опираются на знакомые Swift-концепции: Arrays, closures, structs, protocols и optionals.
:::
